About me

I hold a degree in Computer Engineering from UniMetrocamp and have worked in software quality since 2020, when I started as a QA intern at Venturus. I've been a QA Analyst since 2021, working in cross-functional agile teams.

Day to day, I write and run tests, report defects in Jira, write documentation such as requirements and user guides, test APIs with Postman and run queries and validations on SQL and MongoDB databases.

Before software, I was an electronics technician at Certlab, running certification tests for lithium batteries and SAR according to technical standards. That's where I learned to follow standards rigorously, write reports and juggle deadlines for several clients, and I bring all of that into my QA work.
